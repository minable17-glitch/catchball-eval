# 영상을 구글 드라이브에 저장하기 (앱스크립트 설치 안내)

학생이 올린 영상을 선생님 구글 드라이브에 저장하려면, 앱스크립트(Apps Script)를 선생님 구글 계정으로 **한 번만** 배포하면 됩니다. 약 5분 걸립니다.
제출 목록·채점 결과·공 표시 같은 기록은 그대로 수파베이스에 남고, **영상 파일만** 드라이브에 들어갑니다.
연결하지 않으면 영상은 수파베이스 저장소(무료 1GB, 30초 영상 기준 약 150~200편)에 저장됩니다.

## 1. 앱스크립트 만들기

1. https://script.google.com 에 **선생님 구글 계정**으로 들어가서 **새 프로젝트**를 누릅니다.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 `캐치볼 드라이브` 로 바꿉니다.
3. 편집창에 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 파일 내용을 전부 복사해 붙여넣습니다.
4. 저장(💾 또는 Ctrl+S).

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 > 새 배포**.
2. 왼쪽 ⚙️ 에서 유형 **웹 앱** 선택.
3. 설정:
   - 설명: `캐치볼 1`
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**  ← 학생이 로그인 없이 올리려면 꼭 "모든 사용자"
4. **배포** → 권한 확인 창이 뜨면 선생님 계정 선택 → "고급" → "캐치볼 드라이브(안전하지 않음)로 이동" → 허용.
   (선생님이 직접 만든 스크립트라서 뜨는 경고입니다.)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 3. 앱에 연결

1. 캐치볼 앱 → **선생님** 화면 → 로그인 → **⚙️ 제출 설정 › 열기**.
2. "영상 저장 위치: 구글 드라이브 연결"에 위에서 복사한 웹 앱 URL 을 붙여넣고 **연결**.
3. "연결됐습니다"가 나오면 끝. 선생님 키는 이때 자동으로 만들어져 앱스크립트와 앱 양쪽에 저장됩니다.
   (다른 기기에서 선생님 로그인을 해도 같은 키를 자동으로 씁니다.)

## 어디에 저장되나

- 내 드라이브 > `캐치볼 제출` > `반 이름` > `날짜` > `학생1_학생2_시각.webm`
- 다른 폴더를 쓰려면 앱스크립트 **프로젝트 설정 > 스크립트 속성**에 `ROOT_FOLDER_ID` 를 넣으면 됩니다.
- 선생님 화면의 제출 목록에서 "드라이브에서 보기"를 누르면 그 파일이 열립니다. ✕ 로 지우면 드라이브 파일은 휴지통으로 갑니다.

## 코드를 고친 뒤에는

`Code.gs` 를 수정했으면 **배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포** 를 해야 반영됩니다. URL 은 그대로 유지됩니다.

## 문제가 생기면

- "앱스크립트 응답을 읽을 수 없습니다": 배포 설정의 "액세스 권한"이 "모든 사용자"인지 확인하세요.
- "이미 선생님 키가 있습니다": 앱스크립트 프로젝트 설정 > 스크립트 속성의 `TEACHER_KEY` 값을 연결 화면의 "선생님 키" 칸에 넣고 다시 연결하세요. (앱 쪽 설정을 초기화했거나 다른 수파베이스 프로젝트에 연결할 때 생깁니다.)
- 학생 쪽에서 "드라이브에 직접 올리지 못했습니다"가 떠도, 영상이 40MB 이하면 자동으로 다른 방법(앱스크립트 중계)으로 올라갑니다. 제출 완료 화면이 나오면 성공입니다.
- 채점할 때 영상을 못 가져오면: 선생님 화면 설정에서 "다시 확인"을 눌러 연결 상태를 보세요.
